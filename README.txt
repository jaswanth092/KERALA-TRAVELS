KERALA ESCAPE - TRAVEL DESTINATION WEBSITE

Files:
- index.html : website structure and content
- style.css  : all styling and responsive layout

How to run:
1. Extract the ZIP file.
2. Keep index.html and style.css in the same folder.
3. Double-click index.html, or open it in your browser.

Notes:
- The website uses online Unsplash images and Google Fonts, so an internet connection is needed for those assets.
- The booking form is a front-end demo only. It does not save or send bookings. Connect a backend or form service to receive enquiries.
- Package prices are sample/demo prices.
